\## 1. Описание проекта



\*\*ShopMagazik\*\* — учебный программный проект, разработанный в рамках освоения дисциплины МДК.01.01 «Разработка программных модулей».



Проект предназначен для изучения принципов разработки приложений на языке C#, организации программной архитектуры, взаимодействия с реляционными базами данных и практического применения инструментов разработки.



В рамках проекта рассматриваются создание программных модулей, организация хранения данных, обработка пользовательских операций и взаимодействие приложения с базой данных PostgreSQL.



\## 2. Цель проекта



Разработать учебное приложение на языке C#, демонстрирующее практическое применение технологий программирования, проектирования программных модулей и работы с реляционной базой данных PostgreSQL.



\### Основные задачи



1\. Освоить создание и настройку проектов в Microsoft Visual Studio.

2\. Изучить принципы организации программных модулей на C#.

3\. Освоить проектирование и использование реляционной базы данных.

4\. Изучить инструменты PostgreSQL и pgAdmin 4.

5\. Реализовать взаимодействие программного приложения с базой данных.

6\. Изучить выполнение SQL-запросов и обработку результатов.

7\. Освоить использование Git и GitHub для контроля версий программного проекта.

\## 7. Подготовка базы данных PostgreSQL



Перед запуском приложения необходимо подготовить базу данных.



\### Этап 1. Запуск PostgreSQL



Убедитесь, что сервер PostgreSQL установлен и запущен.



\### Этап 2. Открытие pgAdmin 4



1\. Запустите pgAdmin 4.

2\. Подключитесь к локальному серверу PostgreSQL.

3\. Введите пароль администратора базы данных при необходимости.



\### Этап 3. Создание базы данных



1\. Откройте раздел \*\*Databases\*\*.

2\. Выберите \*\*Create → Database\*\*.

3\. Укажите название базы данных в соответствии с требованиями проекта.

4\. Сохраните изменения.



\### Этап 4. Импорт базы данных



В репозитории расположен файл:



```text

Database/my\_database.sql

```



Порядок его импорта зависит от формата SQL-файла.



Для обычного SQL-скрипта:



1\. В pgAdmin 4 выберите созданную базу данных.

2\. Откройте \*\*Query Tool\*\*.

3\. Загрузите файл `my\_database.sql`.

4\. Проверьте содержимое скрипта.

5\. Выполните SQL-команды.

6\. Убедитесь в отсутствии ошибок.



\*\*Важно:\*\* подробный порядок импорта приведён в отдельном файле:



```text

Database/Импорт БД.txt

```



При настройке базы данных в первую очередь следуйте этой инструкции.



\## 8. Настройка подключения приложения



После импорта базы данных необходимо проверить параметры подключения приложения к PostgreSQL.



Обычно используются следующие параметры:



| Параметр | Пример |

|---|---|

| Host | localhost |

| Port | 5432 |

| Database | Название созданной базы |

| Username | Пользователь PostgreSQL |

| Password | Пароль пользователя |



Пример строки подключения:



```text

Host=localhost;Port=5432;Database=shopdb;Username=postgres;Password=YOUR\_PASSWORD

```



Это пример, а не подтверждённая конфигурация проекта. Фактические параметры должны соответствовать настройкам PostgreSQL и исходному коду приложения.



Не публикуйте реальные пароли и другие секретные данные в GitHub.



\## 9. Запуск проекта



1\. Откройте `ShopManagementApp.sln` в Visual Studio.

2\. Проверьте наличие необходимых зависимостей.

3\. Убедитесь, что PostgreSQL запущен.

4\. Проверьте подключение к базе данных.

5\. Соберите проект через \*\*Build → Build Solution\*\*.

6\. Запустите приложение клавишей \*\*F5\*\*.



Если приложение не запускается, проверьте сообщения об ошибках в Visual Studio, параметры подключения и наличие необходимых компонентов .NET.
